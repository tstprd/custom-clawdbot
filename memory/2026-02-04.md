## Home Assistant Dawn Simulator Bug

**Root cause identified**: HA time triggers with sensor offsets (`sensor.pixel_9_pro_next_alarm - "00:30:00"`) don't recalculate if sensor changes AFTER the calculated trigger time passes.

**Example failure**: Alarm at 7h, sensor updates at 6h35 → trigger was 6h30 (already passed) → HA doesn't reschedule.

**Proposed fix**: Use template trigger instead of time+offset:
```yaml
trigger:
  - platform: template
    value_template: >
      {{ now() >= (states('sensor.pixel_9_pro_next_alarm') | as_datetime - timedelta(minutes=30)) }}
```
