- Location: `_PERSONAL/dashboard/index.html`
- Purpose: Affichage TV avec plans appartement, météo, calendrier, tâches
- Thème: Vert (#4a7c59), texte lisible à distance, français

## Technique HA Forecast Hourly
Pour obtenir les prévisions horaires Home Assistant (met.no) :
```
POST /api/services/weather/get_forecasts?return_response
Body: {"entity_id": "weather.forecast_home_rennes_2", "type": "hourly"}
```
Retourne forecast avec granularité 1h (vs wttr.in = 3h).

## Image Compositing
Plans appartement avec pièces allumées : blend mode "lighten" (PIL) - prend max brightness par pixel pour superposer les overlays des pièces éclairées.

## Entités météo HA
- `weather.forecast_home_rennes_2` (maison)
- `weather.forecast_paris`
- `weather.forecast_lille`
