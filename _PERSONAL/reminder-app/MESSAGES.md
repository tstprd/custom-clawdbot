## Escalade (tâche ignorée)

### Niveau 1 (J+1)

```
🔔 Rappel : Lavabo SDB (5 min)

Ignoré hier. Pas grave, on reprend.

[Faire] [Reporter]
```

### Niveau 2 (J+2)

```
🔔🔔 Le lavabo SDB attend toujours.

Conséquence possible si tu continues à ignorer :
→ Calcaire qui s'incruste
→ Nettoyage 3x plus long après

5 min maintenant = tranquillité.

[Faire] [Reporter à quand ?] [Supprimer]
```

### Niveau 3 (J+3+)

```
⚠️ "Lavabo SDB" ignoré 3 fois.

Soyons honnêtes :
1. Tu le fais maintenant (5 min)
2. Tu me dis quand, sérieusement
3. On supprime — c'est pas important

Pas de jugement. Mais sois honnête avec toi-même.
```

## Erreurs & Edge Cases

### Pas compris

```
🤔 J'ai pas compris.

Essaie :
• "Rappelle-moi de [tâche] [quand]"
• "J'ai fait [tâche]"
• "Mes rappels"
• "Aide"
```

### Aide

```
🆘 Aide — Commandes principales

📋 "mes rappels" → Liste tes rappels
➕ "ajouter [tâche]" → Nouveau rappel
✅ "fait [tâche]" → Marquer complété
⏰ "reporter [tâche]" → Décaler
❌ "supprimer [tâche]" → Retirer

📊 "karma" → Ton score
📈 "stats" → Statistiques
🏅 "badges" → Tes badges
⚙️ "paramètres" → Réglages (heure check-in)

💬 Ou parle-moi naturellement !
```
